These pages assume you already have a running host and its Agent Card URL.

- [Start a watch](start-a-watch/) selects one curated skill and opens one task.
- [Keep the stream open](keep-the-stream/) covers idle streams and reconnect.
- [Ask for current results](current-results/) reads the rows already in the set.
- [Set a lifetime](set-a-lifetime/) says how long the watch stays active.
- [Author a query](author-a-query/) covers hosts that can build a query.
